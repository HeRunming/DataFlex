ICLR 2027 anonymous paper source
================================

Upload this ZIP as a new Overleaf project. Overleaf should detect main.tex as
the root document. If needed, set:

  Main document: main.tex
  Compiler: pdfLaTeX
  TeX Live version: latest available

Keep \iclrfinalcopy commented out for anonymous review.
